# LABMAP 3D 인스타 피드

원고의 핵심을 짧게 재구성해 완성 이미지를 만든다. 기본은 4:5 표지 1장, 본문 2장, 고정 LABMAP 소개 1장의 총 4장이다. 사용자가 정한 장수와 원고를 우선하되 마지막 공통 소개 장표를 항상 포함한다.

## 원고 확인

- 제공된 본문은 바로 사용한다. URL은 해당 서비스의 연결 도구로 읽고 필요한 경우 허용된 브라우저로 확인한다. 비공개 원고를 제목만 보고 추정하지 않는다.
- 공개 글과 예약 글을 구분한다. 접근 불가와 실제 원고 부재를 구분해 막힌 이유와 필요한 입력을 짧게 알린다.
- 글을 골라야 하면 실무적 유용성·핵심 메시지·3D 소재화 가능성으로 하나를 선정한다.
- 원문의 사실·예시·가정을 구분한다. 법령·정책·금융 등 현재성이 중요한 수치는 필요한 1차 출처로 확인한다. 임의 성과·수치를 넣지 않는다.
- 발행 브랜드는 LABMAP으로 적용하고 원문 작성자는 출처로만 구분한다. 사용자 요청이 있으면 브랜드를 바꾸되 공통 소개 장표도 명시적으로 함께 갱신한다.
- 정부기관 레퍼런스의 팔레트와 정보 구조만 참고한다. 기관 로고·캠페인 표장은 복제하지 않는다.

## 기획

1. 표지: 문제·혜택을 큰 제목과 대표 3D 장면으로 제시한다.
2. 본문: 개념, 비용, 절차, 비교 중 하나를 장별 핵심 메시지로 정한다. 각 본문을 3개 패널로 재구성한다.
3. 마지막: 주제별 요약이나 체크리스트 대신 assets/labmap-ending.png를 그대로 사용한다. 요약이 필요하면 마지막 이전 본문 장을 추가한다.

본문은 references/layout.md의 고정 좌표와 글자 크기를 따른다. 글이 길면 축소·재배치하지 말고 문장을 줄이거나 장을 늘린다. 제목은 의미 단위의 2줄로 고정한다. 원고 표현 예시는 references/sample-input.json을 참고한다.

## 제작

### 표지

- 이미지 생성 스킬과 현재 이미지 생성 도구로 3D 표지를 만든다. assets/sample-cover.png는 스타일 참고물이며 해당 주제·원문 브랜드를 새 작업에 자동 복제하지 않는다.
- 밝은 화이트·아이스 블루 배경, 네이비 제목, 둥근 무광·반무광 3D 장면, 좌상단의 부드러운 광원과 접지 그림자를 적용한다.
- 정부 로고, 인스타 UI, 휴대폰 목업, 임의 전화번호를 넣지 않는다. 표지는 본문 고정 그리드의 예외다.

### 본문: 정확한 좌표가 필요한 기본 경로

이미지 생성 모델에 각 장 전체를 다시 그리게 하면 좌표와 글자 크기의 동일성을 보장할 수 없다. 사용자는 모든 본문 요소를 동일한 위치·크기로 고정하도록 요청했다. 따라서 배경과 3D 아트만 생성 도구로 준비하고, 최종 텍스트와 레이아웃은 번들 렌더러로 새로 조판한다.

```bash
python scripts/render_cards.py --input /path/to/cards.json --output /path/to/output
```

- 의존성은 Pillow이다. assets/fonts의 Noto Sans KR 400/700과 OFL.txt를 함께 유지한다.
- JSON의 body_cards에 각 장의 category, title(2줄 배열), subtitle, panels(3개), takeaway를 넣는다. 패널은 heading과 body(최대 2줄 배열)를 가진다.
- references/sample-input.json의 키 형식을 유지한다. 출력은 1080×1350 PNG와 layout-manifest.json이다.
- 렌더러의 텍스트 폭 검사를 통과시키기 위해 글자를 줄이지 않는다. 문구를 줄여 다시 렌더링한다.
- 기본 3개 패널을 모든 본문에서 동일하게 사용한다. 2개 항목은 근거 있는 요약 항목을 더해 재구성하거나 사용자 요구에 맞춰 공통 그리드를 일괄 변경한다. 없는 내용을 만들어 슬롯을 채우지 않는다.
- 정확한 차트·계산은 생성 이미지에 맡기지 않는다. 필요하면 별도 정밀 렌더링을 본문 패널 내부에 동일한 좌표로 넣는다.

### LABMAP 고정 마무리

- assets/labmap-ending.png 파일을 그대로 복사한다. 주제·날짜·출처·페이지 번호·연락처를 추가하지 않는다. 장수가 바뀌어도 동일한 이미지여야 한다.
- 브랜드 문구는 '기술과 비즈니스를 연결합니다.', 보조 문구는 '복잡한 과제를 정리하고, 실행의 방향을 함께 찾습니다.'이다. 기술·전략·실행과 저장 유도를 포함한다.
- 이는 사용자가 요청한 LABMAP 소개를 위한 제작 문구이며 자격·고객 실적·보장 성과에 관한 주장을 추가하지 않는다.
- 마지막 이미지가 없을 때만 렌더러의 render_ending으로 마스터를 재생성하고 시각 검수 후 고정 자산으로 보관한다. 매번 이미지 생성으로 다시 그리지 않는다.

## 검수와 전달

- 모든 카드의 한글·원고 충실성·겹침·잘림·가독성을 실제 이미지로 확인한다.
- layout-manifest.json에서 제목·설명·패널·요약·푸터 좌표와 크기가 동일한지 확인한다. 본문은 동일한 렌더링 함수로 출력한다.
- 페이지 번호가 실제 전체 장수와 맞는지 확인한다. 고정 마지막 장에는 번호를 표시하지 않는다.
- 다른 원고·다른 장수로 출력해도 마지막 파일의 해시가 마스터와 동일한지 확인한다.
- 샘플을 실사용 출력으로 재생성했을 때 원문 브랜드나 정부 표장이 섞이지 않았는지 확인한다.
- 이미지 저장·표시는 현재 환경의 규칙을 따른다. 사용자에게 완성 이미지와 간단한 변경 설명을 제공한다. 요청 없이 실제 SNS에 발행하지 않는다.
