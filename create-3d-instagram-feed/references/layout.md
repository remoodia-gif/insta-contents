그림자를 넣은 3D 큐브와 연한 리본 배경은 공통 아트워크로 사용한다. 기존 샘플의 장마다 달랐던 사물 삽화는 고정 번호 배지와 공통 3D 배경으로 정리했다. 이는 레이아웃 동일성과 텍스트 조판의 정확성을 위한 v2 샘플 방향이다.

표지는 자유로운 대표 3D 장면을 사용하며 이 그리드에서 제외한다. 마지막은 별도 LABMAP 마스터를 반복 사용한다. 본문 글자 크기·좌표를 장마다 바꾸지 않는다. 고정 마지막 장에는 페이지 번호를 넣지 않는다.
